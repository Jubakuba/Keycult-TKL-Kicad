# aftermarket_keycult_tkl

![aftermarket_keycult_tkl](https://i.imgur.com/Y1jk63E.png)

Firmware Source:
https://github.com/qmk/qmk_firmware/keyboards/jubakuba/aftermarket_keycult_tkl


This PCB is ready to order at a fabricator such as JLCPCB.  It supports Keycult TKL 1/2/3.

The /production/ folder contains the gerber.zip bom (bill of materials) and positions file needed.


Instructions:

Upload .zip file.  Request bottom side assembly (top if you want the encoder but can't solder one one yourself).  

Upload bom and positions file when asked.

Any missing components...open the BOM file on your PC.  If JLC says D1 match not found...Bom file...D1...should be LCSC #_____.  Search that component.  Select it on JLC.

Order.

Wait a week.

Flash firmware.

PCB complete.  And you get four extras to share with friends or sell.  I don't care.
